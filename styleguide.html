Web Style Guide — Dark Theme

All CSS tokens, components, and patterns for resonancehq.io. Every element is rendered live from the same CSS used in production. Note: --ff-mono canonically maps to JetBrains Mono per WEBSTYLEGUIDE.md (production index.html currently loads Nunito Sans as a variant).

Three typefaces. Fraunces carries all major headings; Instrument Sans handles UI and body; JetBrains Mono is used for labels, eyebrows, and code.
