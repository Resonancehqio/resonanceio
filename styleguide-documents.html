Document Style Guide — Print & Light Theme

Tokens, patterns, and sizing for standalone HTML document files: pricing overviews, HUD briefs, platform decks, and proposals. Print/Document mode uses its own token set distinct from the main site's dark theme.

Section 01

Two Document Modes

Standalone HTML files fall into two modes. The token sets are distinct — use the right one for your output target.

Property Print / Document Web / Dark
Files pricing-overview.html, hud-overview.html, platform-overview.html nysafah.html, demo.html
Background White / soft lavender (#F7F4FF surround) Dark #09080F
Intended output Print, PDF export, screen share in meeting Browser only — live presentations
Text token set --ink · --ink-2 · --ink-3 · --ink-4 --text-1 · --text-2 · --text-3
Font variables --fd · --fb · --fm --ff-display · --ff-body · --ff-mono
Size units pt for typography, px for layout px / rem / clamp()
Teal color #0D9488 (darker for white bg legibility) #14B8A6
Page sizing @page with letter/landscape None — full-viewport
Nav None (document has no nav) Simplified: logo + CTA only, 64px fixed
Background decoration None Grid layer + animated orbs (.bg-canvas)

Section 04

Document Header Pattern

Every print document opens with a consistent header. Logo mark + wordmark on the left; document title on the right. Separated by a 2px purple rule.

Resonance
Pricing Overview · Confidential
Resonance Platform Pricing

Program-level SaaS for affordable housing relocation & redevelopment.

/* Document header layout */ .doc-header { display: flex; justify-content: space-between; align-items: center; padding-bottom: 10–12px; border-bottom: 1.5–2px solid var(--purple-doc); /* or --teal-doc */ } .doc-wordmark { font-family: var(--fd); font-size: 11pt; color: var(--ink-3); } .doc-title-label { font-family: var(--fm); font-size: 7–8pt; text-transform: uppercase; }
Section 05

Cards & Boxes

Three box patterns: teal accent (capability/feature callouts), purple accent (compliance/risk), and neutral (general content). Border-radius 8–10px for print scale.

Platform capability
AI-assisted unit matching across your entire unit inventory — matching criteria evaluated in seconds, not days.
Compliance requirement
URA documentation required within 90 days of household displacement. Resonance generates notices automatically.
Program note
Pricing is per-program, not per-seat. Contact us to scope your portfolio.
/* Teal accent box */ .box-teal { background: var(--teal-light-doc); border: 1px solid var(--teal-border-doc); } /* Purple accent box */ .box-purple { background: var(--purple-light-doc); border: 1px solid var(--purple-border-doc); } /* Neutral card */ .box-neutral { background: var(--bg-soft); border: 0.5px solid var(--rule); } /* All boxes */ .box { border-radius: 8–10px; padding: 12–20px; }

Section 07

Page Sizing

Two page configurations. Portrait letter for standard documents (pricing, proposals). Landscape for presentation-style decks. Always include print-color-adjust: exact.

Portrait
Letter
8.5 × 11 in
0.55in / 0.72in margins
Landscape
Presentation
11 × 8.5 in
No @page margin
/* Portrait — letter */ @page { size: letter; margin: 0.55in 0.72in; } body { max-width: 816px; margin: 48px auto 80px; } /* Landscape — presentation */ @page { size: 11in 8.5in landscape; margin: 0; } body { width: 1200px; } /* Always include — preserves colors in PDF */ * { -webkit-print-color-adjust: exact; print-color-adjust: exact; } /* Screen wrapper (browser chrome surround) */ html { background: #D6D1EC; } /* or #DDD8EE */
Section 08

Pill / Label Pattern

Print pills are smaller (7pt) and tighter. Dark-web pills are larger (10px) with a pulsing dot. Both share the same shape: mono, uppercase, border-radius: 100px.

Logo rule (both modes)

Always use the full 6-path SVG — one solid path (#9BE2E4) plus five gradient paths (paint0_32–paint4_32). Never a simplified version. In documents, size: 22–28px. In the nav bar: 28–32px.
